# anche-smart-station-3d

安车 3D 智能检测站官网概念项目。

## 项目定位

以“正在运行的智能检测站微缩沙盘”为核心视觉，设计一个滚动驱动的 3D 官网体验。用户从鸟瞰视角看到整站运行，再通过滚动逐步进入入口调度、车辆查验、安全检测、新能源检测、数据中控和监管网络等场景。

核心表达：安车不是单点设备商，而是机动车检测站整站智能化解决方案提供者。

## MVP 方向

第一版只做 5 个核心段落：

1. Hero：运行中的智能检测站
2. 入口调度
3. 安全检测线
4. 新能源检测
5. 数据中控与方案 CTA

MVP 成功标准：一眼能看出是检测站，一眼能看出它正在运转，滚动时能自然进入关键检测环节，并让用户理解安车提供的是整站智能化方案。
